# 桌面窗口使用

AzurLaneWorkbook 桌面窗口提供模拟器选择、游戏数据同步、工作簿生成与浏览、偏好设置以及代理与日志管理等功能。换装计划的核验与执行可通过 [CLI](CLI.md#工作簿流程) 或 [MCP](MCP.md#工作簿操作流程) 完成。

## 启动准备

- 运行环境为 64 位 Windows，程序目录需具备读写 `.suzushiro/` 的权限。
- 在 MuMu12 或雷电 9 中启动《碧蓝航线》，登录账号并进入主界面。
- 确认模拟器已开启 Root 权限，具体要求见 [运行环境](RUNTIME.md#连接前提)。

双击运行 `AzurLaneWorkbook.exe`，或在终端中启动：

```powershell
.\AzurLaneWorkbook.exe
```

无参数运行会打开图形界面。控制台启动时终端会等待窗口关闭；需要命令行功能时可直接带子命令运行。

## 界面概览

| 界面区域 / 按钮 | 功能说明 |
| --- | --- |
| 实例选择 | 下拉选择目标模拟器实例（如 `mumu12:0`、`ldplayer:0`） |
| 代理状态 | 查询所选实例的通信代理状态（仅查询，不主动注入） |
| 工作簿选择 | 浏览并选择已生成的 Excel 工作簿 |
| 同步并生成 | 读取当前游戏数据并生成新的工作簿 |
| 打开工作簿 | 调用系统关联程序（如 Excel）打开所选工作簿 |
| 刷新信息 | 重新加载模拟器实例列表、本地工作簿、历史记录与日志 |
| 查看错误详情 | 弹出窗口显示当前操作的失败原因与关联诊断信息 |
| 设置 | 调整偏好配置（生成选项、网络策略、日志详细程度等） |
| 卸载 | 从所选实例的游戏进程中卸载驻留代理 |
| 检查计划 / 执行计划 | 图形界面中当前未开放，配装计划请使用 CLI 或 MCP 操作 |

## 首次同步与查看

1. **刷新状态**：点击“刷新信息”，等待模拟器实例和工作簿列表加载完成。
2. **选择目标**：在实例下拉框中选中游戏所在的模拟器实例。
3. **同步数据**：确认游戏处于主界面，点击“同步并生成”。程序会连接游戏并拉取舰船、装备与仓库数据。
4. **生成文件**：同步完成后会在数据目录生成类似 `fleet-001.xlsx` 的工作簿（若数据未发生变化则会自动复用已有文件）。
5. **打开浏览**：在工作簿列表中选中刚生成的文件，点击“打开工作簿”即可使用 Excel 查看。

## 编辑与执行配装计划

生成的工作簿为当前账号状态的数据快照。在 Excel 中按规范填写换装计划并保存后，通过命令行工具核验并执行：

```powershell
# 1. 检查计划可行性与所需消耗（只读预览）
.\AzurLaneWorkbook.exe --instance mumu12:0 check fleet-001.xlsx

# 2. 检查并将验证结果与状态写回表格
.\AzurLaneWorkbook.exe --instance mumu12:0 check-save fleet-001.xlsx

# 3. 正式执行换装计划
.\AzurLaneWorkbook.exe --instance mumu12:0 execute fleet-001.xlsx
```

- `check` 在计划有操作要求时读取当前游戏状态并核验资源，不执行装备写入。
- `execute` 会备份工作簿，连接游戏执行实际装配与强化操作，并将最新状态回写至工作簿中。
- 操作完成后回到图形界面点击“刷新信息”，即可更新文件列表并浏览最新结果。详细规则见 [工作簿使用说明](WORKBOOK.md#换装计划完整流程)。

## 偏好设置

点击主界面的“设置”按钮可打开配置面板（修改后需点击“保存”生效）：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用获取方式列 | 关闭 | 开启后工作簿中包含舰船获取途径列，按更新策略读取缓存或联网更新 BWiki 资料 |
| 获取方式更新策略 | 使用缓存 | `use_cache` 仅读取本地缓存；`refresh` 每次生成时在线刷新 |
| 详细诊断日志 | 开启 | 是否在日志中记录完整的细粒度调试信息 |
| 同步完成后卸载代理 | 关闭 | 开启后每次同步完成自动卸载游戏内代理；关闭则保持常驻以便下次快速复用 |

配置统一保存在 `.suzushiro/settings.json`，在 GUI、CLI 与 MCP 间通用。

## 代理常驻与卸载

- 通信代理注入游戏进程后默认保持常驻，会话身份与运行资源匹配时，后续通过 GUI 或命令行可直接复用，无需重复注入。
- 点击“代理状态”可查询当前连接与版本信息；点击“卸载”可主动移除代理。
- 同一模拟器实例同一时刻只允许一个工具客户端连接。

## 历史记录与日志排查

- 主界面下方展示历史操作记录与运行日志列表，编号日志按编号倒序，历史按记录时间倒序排列。
- 选中某条日志或历史记录后，点击“打开日志”即可调用系统默认程序查看完整内容。
- 若同步或执行过程中出现错误，点击“查看错误详情”可快速查看报错摘要与对应日志索引。

## 取消与退出

- 点击窗口右上角关闭按钮会发起安全退出，程序会等待当前进行中的数据读取或文件落盘安全收尾。
- 取消操作不会回滚已经发送给游戏的装备动作；若在执行过程中强退或异常中断，请重新同步并核对实际游戏状态。
