# AzurLaneWorkbook

AzurLaneWorkbook 是一款运行在 Windows x64 上的碧蓝航线数据与配装管理工具。它能连接 MuMu 模拟器 12 或雷电模拟器 9，通过桌面窗口、命令行（CLI）以及 MCP 接口读取游戏数据、生成 Excel 工作簿；批量调整装备使用 CLI 或 MCP 接口。

## 能做什么

- **查看与导出数据**：查询账号内的舰船、装备、材料、物资、编队与舰船科技，并一键导出为 Excel 工作簿。
- **配装与装备管理**：支持装备穿脱、跨船调拨、强化、合成与拆解。操作前自动核算材料、物资与背包容量，执行后同步回读游戏实际状态。
- **免工作簿快速操作**：通过命令行或 MCP 就能查数据、动装备。
- **静态配置与 Wiki 资料**：内置舰船、装备和技能基础图鉴查询，可按需拉取 BWiki 的获取途径并在本地缓存。
- **操作记录与回执**：保存详细的操作历史与诊断日志。

## 第一次使用

1. **下载或构建程序**：将 `AzurLaneWorkbook.exe` 放到有写入权限的目录下（运行时会在同级生成 `.suzushiro/` 存放配置和数据）。若需从源码构建，参考[开发与构建指南](docs/DEVELOPMENT.md)。
2. **准备模拟器**：准备好 MuMu 模拟器 12 或雷电模拟器 9，确保已开启 Root 权限且游戏能正常运行，具体环境要求参见[模拟器与运行环境](docs/RUNTIME.md)。
3. **启动游戏与程序**：在模拟器中进入游戏并登录到界面。双击运行 `AzurLaneWorkbook.exe`，在窗口中刷新并选中当前模拟器实例。
4. **生成表格**：点击界面上的“同步并生成”，完成后点击“打开工作簿”。如果只需要查看船坞和装备，到这里即可。

## 使用入口

| 入口 | 适合的任务 | 使用说明 |
| --- | --- | --- |
| 桌面窗口 | 选择实例、同步生成、打开工作簿、调整偏好、查看历史与日志 | [GUI 使用说明](docs/GUI.md) |
| CLI | 脚本查询、工作簿计划检查与执行、直接操作装备、维护排查 | [CLI 使用说明](docs/CLI.md) |
| MCP | 在支持 stdio MCP 的客户端中调用查询、计划制定与长任务工具 | [MCP 使用说明](docs/MCP.md) |

三个入口共用同一目录下的配置、工作簿和后台代理。图形界面的实例选择仅对当前窗口生效；使用 CLI（`--instance`）和 MCP（`instance`）时建议明确指定目标实例。

在程序所在目录可先查看帮助与实例列表：

```powershell
.\AzurLaneWorkbook.exe --help
.\AzurLaneWorkbook.exe instances
```

命令行直接操作装备时默认只做模拟检查，加上 `--apply` 参数才会真正执行；工作簿的 `execute` 命令则直接执行计划。MCP 执行计划时必须带上检查阶段返回的 `plan_hash`。
